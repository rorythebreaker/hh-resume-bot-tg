# Локальное распознавание CAPTCHA

Основной движок — мобильная модель кириллицы PP-OCRv5 через ONNX Runtime.
Она устанавливается в Docker-образ при сборке с проверкой SHA-256. Перед
распознаванием проверяются варианты выпрямления дуги и обработки фона.
Для автоответа требуется совпадение нескольких вариантов и высокая уверенность.
GPU, API-ключ и отправка картинки сторонним сервисам не нужны.
Tesseract остаётся запасным движком для окружений без установленной ONNX-модели.

OCR включён по умолчанию. Переключатель для каждого профиля находится в Mini App:
AI → OCR CAPTCHA. Отключение сохраняется вместе с настройками профиля.

На новую проверку выполняется не более одной автоматической попытки. Пустой
результат, низкая уверенность, ошибка или таймаут OCR переводят процесс к ручному
вводу. Если HH запрашивает новую CAPTCHA после автоответа, она показывается
пользователю. Автоматическая попытка снова доступна после успешно отправленного
отклика. Прежний предел трёх неподтверждённых CAPTCHA подряд сохраняется.

Распознавание ограничено бюджетом около десяти секунд и одним вычислительным
потоком. Текст ответа не пишется в лог. OCR_DIAGNOSTIC показывает только причину
отказа, количество вариантов, время и оценку уверенности. В статусе Mini App
отображается ход проверки.

Сильно искривлённый текст и сложный фон могут не распознаться. Проверка CI на
чистом тестовом изображении подтверждает работу установленного движка, но не
гарантирует прохождение CAPTCHA HH.

## Проверка на размеченных примерах

На частном наборе из десяти примеров прежняя версия дала ноль точных автоответов.
Новая выбрала три точных ответа, оставив семь для ручного ввода. Неправильных
выбранных ответов на этом наборе не было. На трёх отложенных контрольных примерах
выбран один правильный ответ, остальные два оставлены пользователю. Это небольшой
набор, а не оценка точности на всех CAPTCHA HH.

Для повторной проверки внутри контейнера:

```bash
python tools/ocr_benchmark.py /private/OCR.docx --report /private/report.json
```

Документ должен содержать картинку и правильный ответ в одном абзаце. Отчёт
содержит только номера примеров, результаты и время; изображения и ответы в него
не записываются. Частные документы исключены из Docker-контекста.

Источник модели: PaddlePaddle cyrillic_PP-OCRv5_mobile_rec, конвертация ONNX RapidAI.
Адрес и SHA-256 закреплены в install_ocr_model.py. Лицензии и происхождение:
